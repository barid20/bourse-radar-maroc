BOURSE RADAR MAROC — النسخة التجريبية الأولى

محتويات الملف:
- index.html: واجهة التطبيق.
- manifest.webmanifest و sw.js: ملفات تثبيت PWA والعمل الأساسي دون اتصال.

مهم:
كل الأسعار والأحجام والنسب في هذه النسخة افتراضية لأغراض التصميم فقط.
التطبيق غير مربوط حالياً ببورصة الدار البيضاء ولا يرسل إشعارات حقيقية.

الخطوة التالية:
نشر هذه الملفات على استضافة HTTPS مجانية (مثل GitHub Pages أو Cloudflare Pages)، ثم فتح الرابط في Chrome على الهاتف واختيار:
⋮ > إضافة إلى الشاشة الرئيسية / تثبيت التطبيق.

قبل عرض إشارات حقيقية، يجب تحديد مصدر بيانات يسمح باستخدام الأسعار والصفقات ودفتر الأوامر، والتحقق من شروط الترخيص والتأخير.
